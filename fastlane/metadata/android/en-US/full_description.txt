VeloSpot helps cyclists find and navigate to bike parking facilities across Germany, France and Luxembourg – and stays with you for the whole ride: recording, statistics and analysis included. Fully offline, without proprietary services and without any tracking.

The app ships with over 100,000 bike parking spots from OpenStreetMap, bundled as a SQLite database directly inside the app. All spots are visible from the very first launch, no network connection required.

<b>Map &amp; Data</b>
• Interactive vector map via MapLibre (OpenFreeMap Liberty style, no API key required)
• 100,000+ bike parking spots from OpenStreetMap, fully available offline
• 2D/3D view, dark mode and AMOLED map style
• Viewport-based loading – only the visible map area is queried
• Automatic address resolution and search via Photon (OpenStreetMap-based)

<b>Navigation</b>
• In-app bike routing rendered directly on the map – no handoff to an external app
• Offline routing with BRouter (profiles: Trekking, Fast, Shortest, Mountainbike, Gravel)
• Online routing via OSRM as automatic fallback
• Live turn-by-turn voice navigation with a 3D view
• Drop a custom pin, plan round trips, download offline regions

<b>Record &amp; analyse rides</b>
• Background ride recording (foreground service, notification, Quick Settings tile, home-screen widget)
• "My rides" timeline with a statistics dashboard
• Detailed analysis: animated replay, per-km splits, climbs, best efforts, achievements
• Heatmap of the tracks you have ridden
• "VeloSpot Wrapped" – shareable cards for single rides and your all-time stats
• GPX import and export (with upload help for Strava, Komoot &amp; co.)
• Bike garage with multiple bikes and service reminders

<b>Live data on the go</b>
• Trip Computer HUD with live speed, distance, time, elevation and grade
• Optional weather on the map and with every ride (Open-Meteo, no account)
• External Bluetooth sensors: speed, cadence, power, heart rate

<b>Usability</b>
• Favourites and saved places with a dedicated navigation shortcut
• Current location with map recentring
• 8 languages with persistent language picker: German, English, French, Italian, Portuguese, Luxembourgish, Dutch, Spanish

<b>Privacy &amp; Transparency</b>
• No ads, no tracking, no telemetry
• No proprietary Google services (F-Droid build uses only free/open libraries)
• No account required
• All map data is from OpenStreetMap (ODbL licence); weather data from Open-Meteo
• Source code: https://github.com/drzeeb/VeloSpot

<b>Tech Stack</b>
Android 8.0 (API 26)+ · Jetpack Compose · MapLibre · Room/SQLite · BRouter · OSRM · Photon · Hilt · Retrofit · Kotlin
